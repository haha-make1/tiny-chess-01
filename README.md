A 4 KB Python chess engine for the [tiny-chess-01 bounty](https://make.fun/bounty/tiny-chess-01): 0x88 board, negamax with alpha-beta, transposition table, quiescence search and iterative deepening to a fixed 100,000 nodes per move. Deterministic: no clock, no randomness, no model calls.

## Run

    MAKEFUN_ENV_URL=http://127.0.0.1:18081 python3 -P -s main.py
